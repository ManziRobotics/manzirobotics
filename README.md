## Manzirobotics 🌊🤖

**Humanlike robots for aquatic environments.** We build AI-powered humanoid water robots for rescue operations and underwater exploration, from Zambezia, Mozambique.

> *Mission:* revolutionise water rescue and underwater exploration through advanced humanoid robotics, saving lives and expanding human capabilities in aquatic environments.

- 🛟 **Water rescue** – real-time victim detection, autonomous navigation, emergency response protocols
- 🔬 **Underwater exploration** – deep-water operation, HD imaging, sample collection, long-duration missions
- 🧠 **AI intelligence** – machine learning, predictive analytics, adaptive behaviour, remote monitoring

### 🔭 Tech we're exploring

| Technology | What we use it for |
|---|---|
| [ROS 2](https://github.com/ros2/ros2) | Robot software framework linking sensors, control and autonomy |
| [ArduPilot / ArduSub](https://github.com/ArduPilot/ardupilot) | Open-source autopilot for underwater vehicle navigation and stabilisation |
| [Gazebo](https://github.com/gazebosim/gz-sim) | Simulating robots and missions before they get wet |
| [Ultralytics YOLO](https://github.com/ultralytics/ultralytics) | Real-time vision for detecting people in the water |
